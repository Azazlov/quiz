# 📚 Quiz Platform — Система тестирования для образовательных учреждений

![Локальная сеть](https://img.shields.io/badge/Локальная%20сеть-без%20интернета-brightgreen) ![Flask](https://img.shields.io/badge/Flask-Python-blue) ![Zero-DB](https://img.shields.io/badge/Без%20БД-JSON%20+%20.env-9cf)

Клиент-серверное приложение для проведения тестирования детей в локальной сети школы/класса. Преподаватель управляет тестами через дашборд, ученики проходят тесты на своих устройствах без необходимости установки ПО.

---

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- Браузер на всех устройствах (Chrome, Firefox, Safari, Edge)

### Установка и запуск
```bash
# 1. Клонируйте репозиторий (если ещё не сделано)
git clone https://github.com/Azazlov/quiz
cd quiz

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите сервер
python app.py
```

Приложение будет доступно по адресу: **`http://<IP_вашего_компьютера>:8000`**

> 💡 Совет: Узнайте локальный IP компьютера с сервером:
> - Windows: `ipconfig` → найти «IPv4-адрес»
> - macOS/Linux: `ifconfig` или `ip a`

## ⚙️ Настройка приложения

### Файл `.env` (настройки администратора)
Создайте файл `.env` в корне проекта:

```env
ADMIN_LOGIN=логин_без_кавычек
ADMIN_PASSWORD_HASH=хэш_пароля_без_кавычек (например 8d969eef6ecad3c29a3a629280e686cf0c3f5d5a86aff3ca12020c923adc6c92)
SECRET_KEY=пароль_для_подписи_куки_без_кавычек
```

- `ADMIN_LOGIN` — логин для входа в дашборд (по умолчанию: `admin`)
- `ADMIN_PASSWORD_HASH` — SHA256-хеш пароля (по умолчанию `secret123`)
- `SECRET_KEY` — пароль для подписи куки (по умолчанию `dev-secret-key`)

> 🔐 Как сгенерировать хеш нового пароля:
> ```python
> import hashlib
> print(hashlib.sha256('ваш_пароль'.encode()).hexdigest())
> ```

Если файл `.env` отсутствует — используются значения по умолчанию:
- Логин: `admin`
- Пароль: `secret123`

### Файл `ip_names.json` (имена устройств учеников)
Хранит соответствие между уникальным идентификатором устройства и человекочитаемым именем:

```json
{
  "afa5cf0b2710fe6a": "Макбук Алины",
  "3d8f2a1c9b4e7d0f": "ПК в углу класса",
  "7e2b5c8a1d9f3e6b": "Планшет №3"
}
```

- Заполнять вручную **не обязательно** — можно редактировать имена прямо в дашборде в блоке `Группы по UUID`
- Идентификатор генерируется автоматически при первом подключении устройства

## 👥 Как использовать систему

### Для преподавателя (дашборд)

1. **Войдите в систему**
   - Перейдите на `http://<IP_сервера>:8000/login`
   - Введите логин/пароль из `.env` (по умолчанию: `admin` / `secret123`)

2. **Выберите тест и уроки**
   - В разделе «Управление уроками» выберите тест из списка (например, `run_marco.json`)
   - Отметьте галочками уроки, доступные для прохождения
   - Нажмите «Применить»

3. **Следите за процессом**
   - **Активные сессии** — кто сейчас проходит тест (прогресс в реальном времени)
   - **Недавние сессии** — завершённые попытки с результатами
   - **Статистика** — средние баллы, время прохождения, распределение оценок

4. **Группировка по устройствам**
   - Все сессии с одного устройства объединены в группу
   - Видно как «официальное» имя из `ip_names.json`, так и имя, введённое учеником

### Для ученика (фронтенд)

1. **Подключитесь к тесту**
   - Откройте `http://<IP_сервера>:8000` на своём устройстве
   - Доступные уроки выделены ярким градиентом, недоступные — затемнены

2. **Начните тестирование**
   - Нажмите на карточку доступного урока
   - В появившемся окне введите своё имя
   - Нажмите «Начать тест»

3. **Прохождение теста**
   - На каждый вопрос — 4 варианта ответа
   - Время не ограничено, но **только одна попытка** на урок
   - После завершения — 10-минутный кулдаун перед повторным прохождением (защита от «пролистывания»)

4. **Результаты**
   - После последнего вопроса откроется страница с итогами:
     - Общий балл и оценка
     - Детализация по каждому вопросу (ваш ответ / правильный ответ)
     - Визуальная индикация: ✅ зелёный — правильно, ❌ красный — ошибка

1. **Создайте JSON-файл** по шаблону `tests/lesson_template.json`:

```json

  "lessons": [
    {
      "id": 1,
      "name": "Занятие 1: Название первого урока",
      "available": true,
      "questions": [
        {
          "id": 1,
          "question": "Текст первого вопроса?",
          "options": [
            "Вариант ответа 1",
            "Вариант ответа 2",
            "Вариант ответа 3",
            "Вариант ответа 4"
          ],
          "correct_answer": 1,
          "points": 1
        },
        {
          "id": 2,
          "question": "Текст второго вопроса?",
          "options": [
            "Вариант ответа 1",
            "Вариант ответа 2",
            "Вариант ответа 3",
            "Вариант ответа 4"
          ],
          "correct_answer": 0,
          "points": 1
        }
        // ... добавьте больше вопросов по аналогии
      ]
    },
    {
      "id": 2,
      "name": "Занятие 2: Название второго урока",
      "available": true,
      "questions": [
        // ... структура вопросов такая же, как и в первом уроке
      ]
    }
    // ... добавьте больше уроков по аналогии
  ]

```

2. **Положите файл** в папку `tests/`

3. **Активируйте в дашборде**
   - Перейдите в «Управление уроками»
   - Выберите ваш тест из выпадающего списка
   - Отметьте нужные уроки галочками → «Применить»

> 📌 Совет: Используйте шаблон промпта [test_generation_template.txt](#шаблон-промпта-для-генерации-тестов)  для быстрого создания тестов через ИИ

## 🔐 Безопасность

- Все данные хранятся локально — нет передачи в облако
- Пароль администратора хранится только в виде хеша SHA256
- Одна попытка прохождения + 10-минутный кулдаун предотвращают списывание
- Уникальный `Device ID` вместе `IP` защищает от подмены устройства при переподключении к Wi-Fi

## ❓ Частые вопросы

**В: Нужен ли интернет для работы?**  
О: Нет. Достаточно локальной сети (роутера) в классе.

**В: Можно ли использовать на планшетах/телефонах?**  
О: Да, интерфейс полностью адаптивный.

**В: Что если ученик закрыл вкладку во время теста?**  
О: Сессия сохраняется. При повторном открытии урока кулдауна не будет, но прогресс потеряется.

**В: Как сбросить результаты?**  
О: Удалите файл `logs.txt` — там хранится история всех сессий.

> 💡 **Совет для учителей**: Перед уроком проверьте подключение всех устройств к одной Wi-Fi сети и откройте дашборд на своём компьютере для мониторинга в реальном времени!
