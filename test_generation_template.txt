Роль

Ты — методист и разработчик образовательных тестов для детей. Создай подробный тест в формате JSON согласно спецификации ниже.

Параметры теста:
• Общая тема курса: [ТЕМА_КУРСА]
• Целевая аудитория: дети [ВОЗРАСТ] лет
• Количество уроков: [КОЛ_УРОКОВ]
• Вопросов на урок: [КОЛ_ВОПРОСОВ_НА_УРОК] (минимум 10)
• Содержание урока 1: [ТЕМА_УРОКА_1]
• Содержание урока 2: [ТЕМА_УРОКА_2]
[• Содержание урока N: [ТЕМА_УРОКА_N]] — при необходимости

Требования к вопросам:
1. Каждый вопрос должен быть самодостаточным — без отсылок к другим вариантам ("а и б правильные") или другим вопросам
2. Формулировки должны быть понятны детям указанного возраста — простой язык, короткие предложения, конкретные примеры
3. Каждый вопрос содержит ровно 4 варианта ответа
4. Только один вариант правильный (индекс 0–3)
5. Неправильные ответы должны быть правдоподобными, но однозначно ошибочными
6. Вопросы должны проверять понимание концепций, а не механическое запоминание
7. Избегай двусмысленных формулировок и "ловушек"

Структура выходного файла (строго валидный JSON):
{
  "title": "[название_файла].json",
  "lessons": [
    {
      "id": 1,
      "name": "Занятие 1: [ТЕМА_УРОКА_1]",
      "available": true,
      "questions": [
        {
          "id": 1,
          "question": "Текст вопроса?",
          "options": ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
          "correct_answer": 0,
          "points": 1
        },
        // ... [КОЛ_ВОПРОСОВ_НА_УРОК] вопросов
      ]
    },
    {
      "id": 2,
      "name": "Занятие 2: [ТЕМА_УРОКА_2]",
      "available": true,
      "questions": [ ... ]
    }
    // ... остальные уроки
  ]
}

Дополнительные указания:
• Название файла должно отражать тему курса латиницей (например: "run_marco_basics.json")
• Все тексты на русском языке
• Правильные ответы равномерно распределены по позициям (0, 1, 2, 3)
• Баллы за каждый вопрос = 1
• Проверь валидность JSON перед выводом (запятые, кавычки, скобки)
